# Salon Liora – Friseursalon Demo

Fiktive Referenz-Website für einen Friseursalon – gebaut mit [Next.js](https://nextjs.org), [Tailwind CSS](https://tailwindcss.com) und TypeScript.

Alle Inhalte, Orte und Personen sind beispielhaft. Die Bilder sind KI-generiert und als WebP lokal gehostet.

## Tech-Stack

- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**
- **Tailwind CSS 4**
- **Deployment:** [Vercel](https://vercel.com) (empfohlen)

## Lokale Entwicklung

```bash
npm run dev
```

Im Browser öffnen: [http://localhost:3000](http://localhost:3000)

Weitere Befehle:

```bash
npm run build   # Produktions-Build
npm run start   # Produktions-Server lokal
npm run lint    # ESLint
```
